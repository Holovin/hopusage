# Contributing to HopUsage

HopUsage is a personal, unofficial fork of [OpenUsage](https://github.com/robinebers/openusage). It
stays on the 0.7 line and backports selected changes from newer OpenUsage releases.

- **Features and providers** belong in the original project. Propose them there; this fork picks them
  up when it backports a release.
- **Bugs specific to this fork** (the rename, the switched-off updater, telemetry, or iCloud Sync, a
  broken backport) can be reported as an [issue](https://github.com/Holovin/hopusage/issues).
- **Pull requests** are welcome for fork-specific fixes. Keep them small and follow the PR structure
  in [AGENTS.md](AGENTS.md).
- **Security issues** go through [SECURITY.md](SECURITY.md), not public issues.

The OpenUsage name and logo belong to its author; see the [trademark policy](TRADEMARK.md).
